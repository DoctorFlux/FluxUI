# Shared 3D portrait face framing

The user requested Forever's close-up face framing on Retail and every Classic client. [Shared unit portraits](../UnitFrames/FluxUnitFrames_Shared.lua) now apply that existing camera algorithm by capability rather than restricting it to Forever. The supplied `live`, `classic_era`, `classic_anniversary`, `classic` and `forever` Blizzard API references all declare the custom-camera, camera position/target/distance and portrait-zoom APIs used here.

Engine portrait zoom remains the first crop. If the camera is still far, the existing Forever calculation moves along the model's own camera axis and lifts its target toward the head; no race-height table is introduced. Already close animation cameras retain their crop. Baked `RefreshCamera`/`SetCamera(0)` calls are retained only as branch-appropriate fallbacks when custom-camera capabilities are missing. Forever retains its existing no-baked-camera policy. Invalid, non-finite or secret camera measurements are not used for arithmetic.

Player, target, focus, target-of-target, focus-target and pet portraits share this behavior. Model-loaded and shown events reapply framing, with the existing three finite, coalesced camera callbacks now available on every client. Hidden/question-mark portraits skip delayed camera writes. The existing 2D mode, portrait visibility, borders, combat feedback and fallback models remain available. Shared portraits are marked so [legacy portrait compatibility](../Core/FluxAPI/UI.lua) does not replace their event/show handlers or wrap `SetUnit` and undo the crop; external legacy portraits retain that adapter.

[portrait_camera.lua](../tests/portrait_camera.lua) executes the production camera code and portrait constructor across five client capability models. It checks equal framing with Forever, unit binding, animation retention, legacy adapter ownership, missing-API fallbacks, delayed model readiness, question marks, hide/show, bounded callbacks and three rejected mutations. [Idle units](../tests/idle_units.lua) continues to cover empty-unit and 2D behavior. The [full suite](validation/native-mouse-2026-10-23.json) passes 58 scripts and syntax-checks 695 Lua files.

These are desktop tests. Native visuals remain unverified: after reload on each client, compare player races, pets, NPCs, transformations, mounts/vehicles, rapid target changes, missing/out-of-range units, portrait mode switching, UI scale and squeeze. Camera geometry inherited from the Forever fix is not a guarantee of ideal framing for every model asset. No new FPS improvement is claimed.
