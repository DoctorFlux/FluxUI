# Glossary

Historical names remain active contracts; similar labels can refer to different storage/lifecycle domains.

| Term | Current meaning |
|---|---|
| Accent | Profile-selected class/atlas/custom chrome. Forever atlas mode uses explicit gold RGB. |
| Account scope | Often a branch of the active Ace profile, rather than a global table shared by all profiles. |
| Action strip | Main keyboard bar/minirows; sometimes the whole bottom grid/bar/trinket/Info console. Frame names disambiguate. |
| Occupancy | Action slot type+ID, distinct from a conditional macro's shown face. |
| AfterLoad | Kernel phase after TOC execution; independently delayed feature initialization may remain. |
| AfterLogin | Kernel phase before registered modules enable, with already-logged-in fallback. |
| Already Known | Collectible-learning tint with client-specific item display paths. |
| Assisted Combat | Blizzard assistant identity/highlight surfaced where supported. |
| Aura duration object | Native timer payload accepted by supported display methods. |
| Badge | Alternate action face attached to a primary host. |
| Bank sentinel | Category enum identifier that must not be scanned as a container. |
| Binding document | Per-character FluxBindingDB3 version 3 action/key/form/order data. |
| Binding plan | Derived secure overrides/action/placement program. |
| Camelot/Forever | Distinct runtime grouped under midnight module family; not live Midnight. |
| Capability | Runtime API/widget/event/enum probe or policy flag. |
| Character scope | General character profile or independently selected db.char feature branch. |
| Chord | Normalized key plus modifiers. |
| Combat Grid | Combat consumable/ammo utility row. |
| ConsumableBest | Classification/scoring/memory for food/water/bandage/potion selection. |
| Context | Fingerprinted display refresh bus for unit/modifier/mouseover/combat state. |
| Defaults pack | Game CVar/key/modified-click setup, distinct from Ace defaults; first account apply is automatic. |
| Display tier | Face/icon/usability/badge refresh separate from plan evaluation. |
| Equipment preset | Gear-focused Respec data narrower than a full load profile. |
| Eval tier | Macro/occupancy/binding evaluation stage. |
| Extra Buttons | Shared custom-button engine and Flux Window category editor; grids are additional consumers. |
| FLUX_API | Legacy global facade; its isClassic means Era. |
| Flux.API | New grouped adapters, usually aliased directly on Flux. |
| Flux Window/Battlezone | Bottom-right Map/Meter/Respec/Buttons hub; Battlezone persists in folders/options. |
| Flyout | Item/mount/spell popup with secure actions, favorites and host chrome. |
| FormStorm | Signature-gated form/page/stealth/vehicle burst and settle coalescer. |
| Fresh/modified | GetState's sample comparison to Blizzard defaults, not a complete Flux-settings match. |
| Gamepad HUD | Native style-selected UI, distinct from connected hardware/ConsolePort. |
| Gold ledger | Persistent multi-character gold records. |
| Horizontal squeeze | X-only compression near the UI scale floor to fit available bounds. |
| Identity/shown face | Published kind/ID after context/macro resolution, separate from occupancy/document identity. |
| Inventory facts | Indexed live/stored location/character/account item/currency information. |
| Junk | Explicit/rule-based sell/destroy state with gear/tier protection. |
| Layout | Scoped HUD presets; WindowMover owns Blizzard window drag/scale. |
| Legacy facade | Core/FluxAPI globals/ns.API beside newer Core/API. |
| Load profile | Respec orchestration of enabled talent/gear/rune/bar/utility/consumable/binding sections. |
| Map provider/pin router | Sources and projected map-pin routing/tooltips. |
| Minirow | Shift/Control row associated with main columns. |
| Module | Strictly a Flux.Module lifecycle spec; many folders instead own direct events/timers. |
| Mouseover cast | Click-time unit selection or authored macro targeting, distinct from visual hover preview. |
| NonCombat Grid | Mount/hearth/teleport/food/water/consumable/utilities; installed secure actions can remain usable in combat. |
| Optional dependency | Companion readiness that enables integration, distinct from an embedded library. |
| Paging | Form/stance/vehicle/override occupancy change. |
| Promotion | Smart-layout display of minirow content on a main visible face. |
| Protected gear | Items required by saved gear/profile data, guarded in multiple sale/junk/salvage/transfer routes. |
| Regen queue | Post-combat jobs; named replacement and light/heavy list queues differ. |
| Restock target | Desired item/tier quantity for bank/merchant flows. |
| Restricted closures | SecureHandler snippet/Execute/WrapScript support, disabled on Forever. |
| Rune preset | Respec rune configuration where the native system exists. |
| Salvage | Modifier-held eligible profession/opening actions. |
| Scheduler | Ordered layout/display/eval/structural/inventory buckets. Token sets do not dedupe all callbacks. |
| Secret value | Payload with restricted Lua access separate from display eligibility. |
| Secure click proxy | Separately parented hardware-click forwarding overlay. |
| Slot program | Derived representation joining occupancy, compiled targeting and display modes. |
| SpellBook bus | Debounced signature-changing book notifications, not every raw SPELLS_CHANGED. |
| Stance hybrid | Native forms plus additional spell slots/order. |
| Structural tier | Secure/widget changes deferred in combat. |
| Tier restock | Category/tier goals tied to ConsumableBest/inferior junk. |
| Ticker | Shared demand-armed OnUpdate; count zero does not describe every legacy frame. |
| Trinket Menu | Equipped actions, bag flyouts and swap queues. |
| Unified border | Live-geometry envelope and gap fills. |
| Utility slots | Four character-assigned slots with bindings/snapshots. |
| Warband bank | Account containers/topology separate from character bank/sentinels. |
| WindowMover | Catalog-driven Blizzard window movement/scaling. |
