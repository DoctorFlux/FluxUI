# Glossary

Shared terms used across the FluxUI concept docs.

| Term | Meaning |
|------|---------|
| **Accent** | Global color identity for Flux borders/backdrops: class, atlas-natural, or custom RGB. |
| **Action strip / bottom console** | NonCombat grid + main action bar + Combat grid + Trinket Menu treated as one sealed HUD. |
| **Already Known** | Tint for collectibles the character has already learned, shown at vendors and similar UIs. |
| **Assisted Combat** | Blizzard helper feature surfaced as a Flux bind where the client provides it—not Flux combat AI. |
| **Badge / corner badge** | Small corner preview on an action slot showing an alternate action (often from binding reverse/preview). |
| **Battlezone / Flux Window** | Docked bottom-right tabbed hub (Map, Meter, Respec, Buttons). |
| **Binding document** | Clicked-style saved description of what a key/action does under conditions. |
| **Chord** | Key plus modifiers (SHIFT/CTRL/ALT combinations) routed to main, minirow, or free overrides. |
| **Combat Grid** | Compact combat consumables row (pots, bandage, healthstone, mana, ammo, optional SBA). |
| **ConsumableBest** | Memory of best food/water/bandage/potion tiers for buttons and restock inferior marks. |
| **Defaults pack** | Recommended CVar/keybind sets Flux can apply on setup or reset. |
| **Equipment preset** | Named gear-only set inside Respec (smaller than a full profile). |
| **Extra Buttons** | Player-built category palettes of custom utility buttons. |
| **Flyout** | Popup grid of items/mounts/spells opened from a button or macro. |
| **Fresh vs modified** | Whether critical Flux default settings still match recommendations. |
| **Gold ledger** | Multi-character gold totals for tooltips/status. |
| **Horizontal squeeze** | Narrowing the bottom strip (and related frames) so the Flux Window does not overlap at low UI scale. |
| **Info frame** | Small FPS/ping/durability/stats widget with placement options. |
| **Junk** | Items marked for selling/destroying via Scrap-style rules or manual lists. |
| **Layout scope** | Account/character scope specifically for HUD placement preview, independent of some feature scopes. |
| **`/fluxui`** | Opens FluxUI Options (also `/fluxoptions`). |
| **Load profile** | Full Respec orchestration (talents/loadouts, gear, runes, bars, consumables, utility, bindings). |
| **Map Pins** | World-map-like icons mirrored onto the battlezone map. |
| **Meter tab** | Flux Window host for Details! or Blizzard damage meter layouts. |
| **Micro menu** | Flux replacement for Blizzard’s micro bar, plus Bags/Macros/Addon/Config/Reload/professions. |
| **Minirow** | SHIFT or CTRL secondary/tertiary row above/below a main action column. |
| **NonCombat Grid** | Out-of-combat utilities: mount, hearth, teleport, food/water, consumables, utility slots. |
| **Paging** | Swapping what the main 12 columns show for forms, stealth, vehicle, skyriding, etc. |
| **Promotion (smart layout)** | Showing minirow content on an empty main face until layers expand. |
| **Protection (gear-set)** | Blocks selling/junk/DE on items required by saved Respec profiles/presets. |
| **Restock target** | Desired bag count for an item or consumable tier, optionally counting bank. |
| **Rune preset** | SoD-oriented preset bundling runes with bars/utility. |
| **Salvage** | Modifier-held overlay actions: prospect, mill, DE, open, etc. |
| **Secret values** | Midnight mechanism limiting addon decision-making on combat-sensitive data while still allowing display. |
| **Skyriding / dragonriding page** | Retail bonus action page while dragonriding/skyriding. |
| **Stance bar (hybrid)** | True shapeshift/form buttons plus extra spell slots, reorderable. |
| **Tier restock** | Restocking by consumable tier (food/water/pots/bandages) and marking inferior tiers as junk. |
| **Trinket Menu** | Two equipped trinket slots plus bag flyout and swap queue UX. |
| **Unified border / envelope** | Continuous Flux chrome around the bottom console (and optional micro+status). |
| **Utility slots** | Four player-assignable NonCombat slots with keybinds. |
| **Warband bank** | Retail account-wide bank topology the inventory foundation must understand on Midnight. |
